# telegramspeedreader

Telegram mini app для быстрого чтения книг: слова появляются по одному в центре экрана
(RSVP), опорная буква подсвечена и стоит на месте.

## Что умеет

- **Не убегает, когда отвлёкся.** Текст идёт, пока палец на экране (или режим нажатием),
  сворачивание приложения ставит паузу, после паузы — откат к началу предложения
  (дольше минуты — абзаца) и плавный разгон.
- **Скорость** 100–1000 слов/мин, меняется свайпом вверх/вниз прямо во время чтения,
  у каждой книги своя. Длинные слова, числа и знаки препинания держатся дольше.
- **Главы и страницы:** оглавление, «стр. N из M» (у PDF — настоящие номера страниц),
  минуты до конца главы, полоса прогресса с засечками глав.
- **Иллюстрации, листинги, таблицы, формулы** — «стоп-карточки»: рисунок показывается
  после предложения, где на него впервые сослались. Режимы: останавливаться, мельком,
  пропускать. Короткие команды (`$ git init`) читаются в потоке.
- **Форматы:** EPUB, FB2, PDF, TXT. Всё разбирается прямо на телефоне. PDF — через pdf.js:
  колонтитулы, переносы, две колонки, код, рисунки и формулы вырезаются картинками.
- **Бот:** пришлите книгу файлом в чат — под ней кнопка «Читать». Книги и место в книге
  синхронизируются между устройствами через облачное хранилище Telegram.

## Как устроено (бесплатно)

| Часть | Где |
|---|---|
| Мини-апп (`app/`) | GitHub Pages |
| Бот и выдача файлов (`worker/`) | Cloudflare Workers, бесплатный тариф |
| Файлы книг | в чате с ботом (Telegram хранит их сам) |
| Список книг и прогресс | CloudStorage Telegram |

Ограничение Telegram: бот скачивает файлы до 20 МБ. Книгу больше можно открыть кнопкой
«Добавить» в приложении — она прочитается на этом устройстве.

## Запуск бота — один раз

1. **Бот.** В [@BotFather](https://t.me/BotFather): `/newbot`, сохранить токен.
2. **Cloudflare.** Зарегистрироваться на cloudflare.com (бесплатно, без карты).
   В профиле → API Tokens → Create Token → шаблон «Edit Cloudflare Workers».
   Account ID — на главной странице Workers & Pages справа.
3. **GitHub** → Settings → Secrets and variables → Actions:
   - секреты: `CLOUDFLARE_API_TOKEN`, `BOT_TOKEN` (из п. 1), `WEBHOOK_SECRET` (любая
     длинная случайная строка из латиницы и цифр);
   - переменные: `CLOUDFLARE_ACCOUNT_ID`, `API_URL` — адрес Worker'а,
     `https://telegramspeedreader.<ваш-поддомен>.workers.dev` (поддомен виден в Cloudflare
     в разделе Workers & Pages).
4. **Settings → Pages → Source: GitHub Actions.**
5. Слить изменения в `main`: опубликуются и приложение, и бот.
6. Открыть один раз `https://telegramspeedreader.<поддомен>.workers.dev/setup?key=<WEBHOOK_SECRET>` —
   бот получит вебхук, кнопку «Библиотека» и описание.

## Разработка

```sh
cd app && npm install
npm run dev          # приложение локально
npm test             # движок, разбор EPUB/FB2/TXT/PDF, синхронизация
npm run build        # проверка типов и сборка

cd ../worker && npm install
npm test             # подпись Telegram, ответы бота
```
