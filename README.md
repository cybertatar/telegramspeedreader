# telegramspeedreader

Telegram mini app для быстрого чтения загружаемых книг: слова появляются по одному
в центре экрана (RSVP), опорная буква подсвечена и стоит на месте.

## Что уже есть

- Читалка: «держи и читай» (текст идёт, пока палец на экране) или режим нажатием.
- Автопауза, когда приложение свернули; после паузы откат к началу предложения
  (дольше минуты — абзаца) и плавный разгон.
- Скорость 100–1000 слов/мин, меняется свайпом вверх/вниз прямо во время чтения;
  у каждой книги своя. Паузы на знаках препинания настраиваются.
- Главы и страницы: оглавление, «стр. N из M», минуты до конца главы, полоса
  прогресса с засечками глав, которую можно тянуть.
- Текст на паузе с подсвеченным словом: нажатие на слово — продолжить с него.
- Иллюстрации, листинги, таблицы — «стоп-карточки». Рисунок показывается после
  предложения, где на него впервые сослались («см. рис. 2.1»), а не там, где его
  оставила вёрстка. Режимы: останавливаться, мельком, пропускать.
- Загрузка TXT (в том числе windows-1251) и FB2 с картинками прямо в приложении.

## Дальше

  переносы, колонки, код, вырезка формул и схем, настоящие номера страниц, OCR сканов).
- Синхронизация прогресса между устройствами.

## Разработка

```sh
cd app
npm install
npm run dev      # локально
npm test         # тесты движка и разбора файлов
npm run build    # проверка типов и сборка в app/dist
```

Каждый пуш в `main` публикует приложение на GitHub Pages
(`https://cybertatar.github.io/telegramspeedreader/`). Этот адрес указывается
у бота в @BotFather как адрес мини-аппа.
